# Dwellingplace

一个和 AI 伙伴们待在一起的小空间。可以有不止一个 AI：每位伙伴有自己的名字、头像、性格，也可以接不同的模型；把几位放进同一个「房间」，就能像群聊一样一起说话。

## 运行

纯静态页面，不需要安装或构建：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

（需要用本地服务器打开，直接双击 `index.html` 时浏览器不允许加载 ES 模块。）

第一次打开会有两位演示伙伴「林」和「阿哲」，使用离线演示模式，不需要密钥就能试用界面。

## 功能

- **伙伴**：左侧「伙伴」+ 新建。可设置名字、头像（emoji）、颜色、性格设定，以及使用哪个模型：
  - **Claude**：在「设置」里填 Anthropic API Key，默认模型 `claude-opus-5-5`
  - **OpenAI 兼容接口**：DeepSeek、通义、Moonshot、本地 Ollama 等任何 `/chat/completions` 接口，每位伙伴可以单独指定地址和密钥
  - **演示**：离线随机回复，用来试界面
- **房间**：一个房间里可以有一位或多位伙伴。
  - 「每个人依次回应」或「随机一位回应」两种模式
  - 消息里写 `@名字`，只让被点名的伙伴回答
  - 「让他们继续聊」：你不说话，让伙伴们自己接着聊一轮
  - 回复流式显示，可随时「停止」
- 多人对话里，每位伙伴都能看到谁说了什么（别人的话以 `[名字]: ` 标注），并只以自己的身份回应。

## 数据与隐私

所有伙伴、房间、聊天记录和 API Key 都只保存在当前浏览器的 localStorage 里，由浏览器直接请求对应的模型服务商。因为密钥存放在浏览器中，请只在自己的设备上使用；若要部署给别人用，应该加一个后端来保管密钥。

## 文件结构

```
index.html        页面结构
styles.css        样式（自动跟随系统深色模式，适配手机）
js/store.js       数据与本地存储
js/providers.js   模型接入：Claude / OpenAI 兼容 / 演示
js/app.js         界面渲染、多人对话逻辑、对话框
```
