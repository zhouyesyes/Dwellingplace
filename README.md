# Dwellingplace

和 AI 们待在一起的小地方（栖所）。白 / 浅灰为底、淡淡的多巴胺色点缀，手机、平板直接用浏览器打开，也可以「添加到主屏幕」当作 App 使用。

## 现在有什么

- 底部四个按钮：主页 / 通讯 / 记忆 / 设置
- **主页**
  - 封面、头像、名字可改（换图时可以裁剪）
  - 简介：自己写一段，也可以让每个 AI 各写一段，全部保留并标出是谁写的
  - 小组件桌面：长按进入编辑，可以拖动排序、删除、切换大小、添加
  - 小鸡：点一下换状态（发呆 / 开心 / 睡觉 / 啄米）
  - 纪念日：可以有好几个，左右滑动；每个选择是哪个 AI 的、可换背景；显示第几天和下一个整百天 / 周年
  - 日历：和 AI 们一起记的小事，日期下面用各自的颜色标小圆点；每个人（包括你）的颜色都可以改。AI 在聊天时也可以自己新增、修改、删除日历记录
- **通讯**：每个角色一栏（群聊先占位）。点进去默认打开最近聊的对话
- **聊天页**
  - 左上返回，中间名字 + AI 自己改的签名（有冷却时间，可在角色设置里调整或锁定），右上小房子 = 小世界（占位）
  - 消息带头像和时间戳；AI 知道现在几点、离上次聊天隔了多久
  - AI 的回复会按段落拆成几个气泡
  - 「＋」发送图片、PDF、文本文件；旁边的按钮切换 / 新建 / 重命名 / 删除对话
  - 点一条消息：复制、修改、重新生成、删除
  - 每个对话可以单独换背景（带裁剪）；输入框上方的小标签可以切换模型（只列出星标模型）
  - 每个角色的气泡颜色可以自己定
- **设置**
  - 角色：头像、名字、代表色、设定、签名、使用的 API；以及「在 TA 面前的我」：TA 怎么称呼你、你在 TA 那里的头像、关于你的事（每个角色可以不一样）
  - API：Anthropic 格式（官方或反代）/ OpenAI 兼容格式；可拉取模型、给常用模型点星标；可设全局默认
  - 用量（本机统计）：按 API 汇总，点进某个 API 可以看到每个模型的用量和最近 7 天
  - 字号：小 / 标准 / 大

记忆库、备份、工具，以及 AI 在聊天中写记忆和记日历，会在下一步完成。

## 本地运行

```bash
npm install
npm run dev      # 开发，手机和电脑在同一 Wi-Fi 下可以用终端里显示的局域网地址打开
npm run build    # 生成静态文件到 dist/
```

## 部署到 GitHub Pages（让手机直接打开）

1. 在 GitHub 仓库 **Settings → Pages → Build and deployment → Source** 里选 **GitHub Actions**
2. 把代码合并到 `main` 分支，会自动构建并发布
3. 发布后的网址形如 `https://<用户名>.github.io/<仓库名>/`。用 iPhone Safari 打开 → 分享 → **添加到主屏幕**

## 数据说明

- 所有数据（角色、聊天记录、图片、API 密钥）只存在这台设备的浏览器里（IndexedDB），不会上传到任何服务器
- 浏览器直接请求你填写的 API 接口
- iPhone 上请务必「添加到主屏幕」后使用：普通 Safari 标签页里的网站数据，长时间不打开可能会被系统清掉
- 不同设备之间的数据不同步（之后会做导出 / 导入备份）
