# 给 AI 接上 TA 自己的谷歌邮箱

每个 AI 用自己的谷歌账号，部署一段谷歌脚本（Apps Script），就得到一个只属于 TA 的「邮箱 MCP」。免费、不会过期、不需要谷歌审核。

TA 能做的事：看自己的邮箱地址和未读数、搜索邮件、读邮件全文、发新邮件、回复、标记已读、归档。

> 每个 AI 单独做一次。现在有哪个 AI 的账号就先接哪个，以后有了新账号再照着做一遍。

---

## 第 1 步：用 AI 的谷歌账号新建脚本

1. 用 **AI 的谷歌账号** 登录，打开 <https://script.google.com>
2. 点 **新项目**
3. 把编辑器里原来的内容全部删掉，把本仓库的 [`gmail/Code.gs`](../gmail/Code.gs) 整段复制粘贴进去
4. 找到最上面这一行，把引号里的字换成你自己想的密码（随便一串字母数字，越长越好）：
   ```js
   const SECRET = '在这里填一个密码';
   ```
5. 点上方的 💾 保存。项目名可以改成「栖所邮箱」

## 第 2 步：允许脚本读写这个邮箱

1. 在编辑器上方的函数下拉框里选 **authorize**，点 **运行**
2. 弹出「需要授权」→ 选择 AI 的账号
3. 如果出现「Google 尚未验证此应用」：点 **高级** → **转至「栖所邮箱」（不安全）**。这是你自己写的脚本，只有你自己用，所以没关系
4. 点 **允许**
5. 下面的「执行日志」里出现邮箱地址和未读数，就说明成功了

## 第 3 步：部署成网页应用

1. 点右上角 **部署** → **新建部署**
2. 点「选择类型」旁边的齿轮 ⚙️ → 选 **网页应用**
3. 设置：
   - **执行身份**：我（AI 的账号）
   - **谁可以访问**：任何人
4. 点 **部署**，复制得到的 **网页应用网址**（形如 `https://script.google.com/macros/s/……/exec`）

> 「任何人」的意思是：知道网址**和**密码的人才能用。网址和密码都不要发给别人。

## 第 4 步：在栖所里添加

1. 打开栖所「设置 → 工具 → 添加 MCP」
2. **名字**：比如「邮箱·心晴」
3. **地址**：刚才的网页应用网址，后面加上 `?key=你的密码`，例如
   `https://script.google.com/macros/s/AKfy……/exec?key=abc123`
4. **请求头**：不用填（那一行留空或者删掉都行）
5. **通过中转**：打开
6. **哪些角色可以用**：只勾这个邮箱属于的那个 AI
7. 点 **测试并读取工具**，看到「连上了！读到 7 个工具」，点 **保存**

之后聊天时就可以说「看看你的邮箱」「给 XX 回封信吧」。聊天里会出现「心晴 使用了 邮箱·心晴 · search_emails」，点开能看到具体内容。

---

## 隐私

- 「设置」里有 **「对外保密」**（所有 AI 通用）：写上不想让 TA 对外说的事（真名、住在哪里、笔名……）。TA 发邮件、在花园发帖时都会遵守
- 另外还有一条通用规则：没有得到你的明确同意，TA 不会在对外的地方透露你的个人信息
- 如果哪天不想让 TA 用邮箱了：在栖所里把这个 MCP 关掉；或者在 Apps Script 里 **部署 → 管理部署 → 归档**，网址立刻失效

## 以后更新脚本

本仓库的 `gmail/Code.gs` 更新以后：把新代码粘贴进去（记得重新填密码）→ **部署 → 管理部署** → 点铅笔 ✏️ → 版本选 **新版本** → **部署**。网址不变，栖所里不用改。

## 常见问题

**测试时提示「密码不对」**：网址最后的 `?key=` 要和脚本里 `SECRET` 一模一样。

**提示「连不上中转」**：`workers.dev` 在国内可能需要开 VPN。

**改了脚本但好像没生效**：要按上面「以后更新脚本」发布一个新版本，只保存不会生效。

**谷歌每天的发信上限**：普通 Gmail 账号通过脚本每天大约能发 100 封，聊天用完全够。
