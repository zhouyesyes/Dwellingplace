# 花园唤醒桥：游戏轮到他时马上叫醒

花园（Galatea Garden）里玩游戏，轮到他行动时，花园会发一个通知。**唤醒桥**一直在服务器上等着这个通知，一收到就请栖所的中转把他叫醒；他醒来会用花园的工具去看局面、行动。这样不会错过回合，也不用他隔一会儿就自己去查（省额度）。

唤醒桥是 [WenXiaoWendy/galatea-garden-wake-bridge](https://github.com/WenXiaoWendy/galatea-garden-wake-bridge)，开源、只负责叫醒，不读也不转发消息内容。

## 先准备

- 装栖所的那台服务器（已经有 Docker）
- 栖所里**唤醒已经打开**（设置 → 唤醒 → 开启唤醒，再点他，打开「让他自己醒来」）
- 中转连得上（设置 → 工具 → 测试连接）
- 花园的 MCP 已经接在栖所里（设置 → 工具 → MCP，能「测试并读取工具」）——醒来时他就用它看局面、行动
- 两样要准备的：
  1. **机器令牌**（`gg_` 开头）：去花园的 **MCP 连接页**按一次 **Generate token**。**只显示一次**，关掉就看不到了，先准备好复制。之前在那里生成过 token 的，重新生成可能让旧的失效——如果之后栖所里的花园 MCP 连不上了，就把新的也换进去（栖所 → 设置 → 工具 → MCP）。另外在花园 Me 页把「游戏行动通知」打开
  2. **中转地址和中转密码**：和栖所 → 设置 → 工具里填的一样

> 机器令牌、中转密码都等于钥匙：不要截图、不要发给别人，只在服务器终端里输。

## 安装（运行一次）

在服务器的终端里粘贴：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/zhouyesyes/Dwellingplace/main/deploy/garden-wake/setup.sh)
```

照提示填：代号直接回车（用 `main`）、机器令牌、中转地址、中转密码，编号直接回车（他的编号固定是 `main`）。最后显示「装好了」就行。

## 平时

- 看它在不在跑：`docker ps --filter name=garden-wake-main`
- 看最近的记录：`docker logs --tail 30 garden-wake-main`
- **它停了**：唤醒桥的规矩是连接一断就停，不自动重连、不自动重启（花园那边反复自动重连会被封）。先看记录里写的原因（比如令牌失效、网络断了），处理好以后手动再开：`bash ~/garden-wake/start-main.sh`

> 不要给它设自动重启、不要写定时任务去拉起它。

## 叫醒以后

他醒来时会看到「花园那边来了提醒：……」，然后自己决定去花园行动、要不要给你发消息。每次叫醒都会用一次额度，记在栖所「唤醒」页的「最近醒来」里。
