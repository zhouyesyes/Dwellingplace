# 安全重新导入 EPUB

在共读书架长按已有书的封面，或在阅读器的目录中打开「这本书：进度、评分、读后感」，点「重新导入并覆盖 EPUB」，选择完整的新版 EPUB。核对目标书名、新文件的书名和作者、章节和插图数量、笔记迁移统计，再点「确认覆盖并保留笔记」。操作完成会刷新页面，以新正文和恢复的位置继续使用。

《冬牧场》也走这个入口：选择书架上已有的《冬牧场》，不要点「放一本书」，不需要删除旧书。如果书名/作者不同或正文核对不足，确认按钮不可用；如果文件缺章、缺图、插图损坏，则停在提示，不改旧书。检查所选文件或换用完整 EPUB，不提供强制覆盖按钮。

覆盖后再次打开书籍管理，查看「上次覆盖导入」和「待重新定位 / 未定位笔记」。未定位笔记保留原摘录、原章节、作者和批注；不显示在错误的正文位置。当前只提供查看和保留，不包含正文编辑或手工重新定位界面。

在执行覆盖的同一设备可点「恢复覆盖前备份」。恢复旧正文、封面、进度和原有笔记；覆盖后新增的笔记进入未定位列表保留。每本书只保存最近一次成功覆盖前的本地备份，下次成功覆盖会更新；备份不随同步上传到其他设备。恢复不会删除备份，但恢复后不提供第二次连续向前回滚。

## 匹配与迁移

- 目标始终是管理卡片中的原书 ID，不进行全书架模糊搜索，也不调用新建书籍流程。书架项目位置、书名、作者、自定义封面、阅读时间、评分和其他字段保留。
- 书名经 Unicode/空格/标点规范化后必须一致；双方都有作者时作者也必须一致；旧正文至少 45% 的长段落锚点在新版中仍然存在，否则阻止覆盖。旧版只含图片而没有可核对文字时，保守阻止覆盖。
- 章节综合使用正文锚点、EPUB spine 标识/资源标识、标题和顺序评分。顺序只用于弱辅助，不能单凭数组下标确定章节；分数不足或候选接近时不认定匹配。早期 EPUB 没有保存章节标识时，仍可用标题与正文匹配。
- 笔记先找原完整段落，再核对摘录与原选区偏移；段落改写/拆分时尝试唯一摘录，优先考虑可靠匹配的章节。重复摘录按实际字符位置计数（包括同段内重复和重叠），匹配章节内有多个同等可靠位置时不强行迁移；不会排除重复段落后再选择另一段。缺失文字或过短的孤立锚点也不强行迁移。选区使用全文锚点，保留超过旧 quote 截断长度的原完整选区。
- 阅读位置和其他 from/upTo 等坐标先找相同正文；否则回到匹配章节的相近段落，并在预览和结果中明确提示。章节也无法匹配时回到书首并提示。
- EPUB 图片、alt、题注和资源仍使用已有解析/持久化/显示与共读输入链路；覆盖预检额外检查缺失资源和图片可解码性，没有重新设计图片链路。

## 存储与失败处理

解析、资源检查、数据迁移不写旧书正文。spine 引用缺失的 manifest 项、manifest 缺 href/空 href/无效位置、章节资源不存在时，返回 allowed=false 的异常预览，不能确认覆盖。

从开始重导入起，本页的自动保存也启用并发保护：在同一个 IndexedDB 写事务内读取最新 meta，以本页上次已持久化状态为基线，按字段和稳定 ID 合并无冲突修改。其他实例新增的笔记、进度、时间、阅读统计与本页未落盘的独立设置都保留，不会先用旧内存 flush 覆盖数据库。合并后的目标书或笔记不同于预览时，拒绝旧预览，要求重新预览；正文/meta 在提交前又变化也会被写事务校验拦下。

同字段修改或不同书架排序冲突时不自动取舍，不改数据库的新内容；本页修改和基线另存本机待保存副本，当前标签页刷新可恢复。每个实例使用独立副本键，刷新交接时保留旧副本，复制标签页不会相互覆盖。副本不参加同步。冲突需先核对解决，不能强制覆盖；没有新增冲突编辑或正文编辑功能。

自动保存与覆盖事务串行；自动保存到实际执行时才采集内存，避免排队中的旧状态写回旧章节。覆盖写事务期间本页又有修改则中止覆盖，后续安全保存会保留这份待保存内容。

确认前安全合并本页待保存数据；备份取自合并后确认时最新的持久化书籍及全部笔记，失败回滚保留这份最新状态。覆盖事务按顺序写本地快照（旧正文及资源、整本书元数据、所有笔记、封面 Blob）、新正文及资源、迁移后的书架元数据。三个部分同一事务提交；同步异常、存储配额不足、请求失败或事务中止都会整体回滚。同步通知仅在事务成功后发出，随后才更新内存书架与正文缓存。失败不会更新上一次成功备份。同步仍沿用现有多键同步协议，本文的事务保证针对当前设备的 IndexedDB，不声称跨设备同步也是一个原子事务。

```sh
node scripts/ui-preview.cjs --task 01a14591-414e-77d1-b3fc-a0e3f6d34017 --route /books --fixture book-reimport --views phone --themes light,dark

```

测试使用全新浏览器与虚构书，屏蔽 API 和外网：旧版没有保存章节标识，已有进度、划线、用户/GPT 批注、便利贴、封面设置；新版新增序言、章节重排、插入段落和图片、移除一段旧文。验证事务失败回滚（正文写入、元数据写入及异步 abort）、解析失败、不同书名/作者及缺章/缺图/损坏插图拦截、过期元数据/正文拦截、歧义笔记保留、实际界面选择文件/确认覆盖/刷新、图片解码显示、现有当前页共读采集与 PNG 图片输入（核对题注、alt、中心像素）、稳定书 ID 与笔记定位、恢复快照和恢复后新增笔记保留。没有读取或覆盖真实书籍，没有真实 GPT 请求，也不替代 Safari 真机验收。

复核的三项缺陷在 `scripts/fixtures/book-reimport-regressions.cjs` 中单独回归，由上面的同一命令自动运行：另一数据库连接直接写入新笔记/进度/阅读时间/统计，本页有待保存设置，旧预览必须拒绝且延迟自动保存后仍不丢数据；重新预览后故障回滚/备份/恢复均保护最新数据；覆盖事务期间本页新增笔记会中止并安全保存；同字段冲突保留两份并验证刷新恢复；三本书顺序和封面不变；改写段落的重复/重叠摘录进入未定位；缺 manifest、缺/空 href、缺资源文件四种结构异常均返回禁止覆盖预览。
