# 安全重新导入 EPUB

在共读书架长按已有书的封面，或在阅读器的目录中打开「这本书：进度、评分、读后感」，点「重新导入并覆盖 EPUB」，选择完整的新版 EPUB。核对目标书名、新文件的书名和作者、章节和插图数量、笔记迁移统计，再点「确认覆盖并保留笔记」。操作完成会刷新页面，以新正文和恢复的位置继续使用。

《冬牧场》也走这个入口：选择书架上已有的《冬牧场》，不要点「放一本书」，不需要删除旧书。如果书名/作者不同或正文核对不足，确认按钮不可用；如果文件缺章、缺图、插图损坏，则停在提示，不改旧书。检查所选文件或换用完整 EPUB，不提供强制覆盖按钮。

覆盖后再次打开书籍管理，查看「上次覆盖导入」和「待重新定位 / 未定位笔记」。未定位笔记保留原摘录、原章节、作者和批注；不显示在错误的正文位置。当前只提供查看和保留，不包含正文编辑或手工重新定位界面。

在执行覆盖的同一设备可点「恢复覆盖前备份」。恢复旧正文、封面、进度和原有笔记；覆盖后新增的笔记进入未定位列表保留。每本书只保存最近一次成功覆盖前的本地备份，下次成功覆盖会更新；备份不随同步上传到其他设备。恢复不会删除备份，但恢复后不提供第二次连续向前回滚。

## 匹配与迁移

- 目标始终是管理卡片中的原书 ID，不进行全书架模糊搜索，也不调用新建书籍流程。书架项目位置、书名、作者、自定义封面、阅读时间、评分和其他字段保留。
- 书名经 Unicode/空格/标点规范化后必须一致；双方都有作者时作者也必须一致；旧正文至少 45% 的长段落锚点在新版中仍然存在，否则阻止覆盖。旧版只含图片而没有可核对文字时，保守阻止覆盖。
- 章节综合使用正文锚点、EPUB spine 标识/资源标识、标题和顺序评分。顺序只用于弱辅助，不能单凭数组下标确定章节；分数不足或候选接近时不认定匹配。早期 EPUB 没有保存章节标识时，仍可用标题与正文匹配。
- 笔记先找原完整段落，再核对摘录与原选区偏移；段落改写/拆分时尝试唯一摘录，优先考虑可靠匹配的章节。重复摘录、缺失文字或过短的孤立锚点不强行迁移。选区使用全文锚点，保留超过旧 quote 截断长度的原完整选区。
- 阅读位置和其他 from/upTo 等坐标先找相同正文；否则回到匹配章节的相近段落，并在预览和结果中明确提示。章节也无法匹配时回到书首并提示。
- EPUB 图片、alt、题注和资源仍使用已有解析/持久化/显示与共读输入链路；覆盖预检额外检查缺失资源和图片可解码性，没有重新设计图片链路。

## 存储与失败处理

解析、资源检查、数据迁移和预览都在内存完成，不写旧书。确认时对预览数据再次核对，且在 IndexedDB 写事务中核对旧正文及元数据，拒绝过期预览。

事务按顺序写本地快照（旧正文及资源、整本书元数据、所有笔记、封面 Blob）、新正文及资源、迁移后的书架元数据。三个部分同一事务提交；同步异常、存储配额不足、请求失败或事务中止都会整体回滚。同步通知仅在事务成功后发出，随后才更新内存书架与正文缓存。失败不会更新上一次成功备份。同步仍沿用现有多键同步协议，本文的事务保证针对当前设备的 IndexedDB，不声称跨设备同步也是一个原子事务。
