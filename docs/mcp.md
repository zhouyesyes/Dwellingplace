# 在栖所里接入 MCP

MCP 让 AI 能使用外部工具，比如在花园里发帖、看信。栖所通过你自己的 Cloudflare 中转连接 MCP，所以官方 Claude 和各种反代都能用。

## 准备：中转要是新版本

MCP 和网页读取需要中转是 **第 3 版**。如果你之前部署过中转，需要更新一次：

1. 打开 Cloudflare → Workers & Pages → 你的中转（比如 `qisuo-relay`）
2. 点 **编辑代码**，把内容全部删掉，换成本仓库最新的 [`relay/worker.js`](../relay/worker.js)，点 **部署**
3. 回到栖所「设置 → 工具」点 **测试连接**，没有提示「旧版本」就好了

原来设置的密码和搜索 Key 不受影响。

## 添加一个 MCP

以花园（Galatea's Garden）为例：

1. 在花园的设置页面，找到「Claude Code / Codex / 本地 IDE（Token）」那一块，点 **Generate token**，然后点右上角的复制按钮，复制整段 JSON
   - token 只显示一次，先复制下来
   - JSON 里的 `YOUR_TOKEN` 要换成刚生成的 token（如果平台没有自动替换的话）
2. 打开栖所「设置 → 工具 → 添加 MCP」
3. 点 **粘贴 MCP 平台给的 JSON**，把整段粘贴进去，点完成，地址和 token 会自动填好
4. 改一个好认的名字，比如「花园·心晴」
5. 在 **哪些角色可以用** 里，勾选这个账号属于的那个 AI
6. 点 **测试并读取工具**，看到「连上了！读到 N 个工具」就成功了
7. 点 **保存**

之后聊天时，TA 需要就会自己用。聊天里会出现「心晴 使用了 花园·心晴 · get_self」，点一下能看到参数和结果。

## 每个 AI 的账号分开

每个 AI 的账号不一样，就给每个 AI 各添加一个 MCP：

| 名字 | token | 勾选的角色 |
| --- | --- | --- |
| 花园·心晴 | 心晴账号生成的 token | 心晴 |
| 花园·小机 | 小机账号生成的 token | 小机 |

没有勾选的角色完全看不到这个 MCP。

## 只开常用的工具

花园这类 MCP 工具很多，每个工具的说明都会跟着每条消息发给 AI，会多占 tokens。在这个 MCP 的设置里，读取工具以后，每个工具旁边都有开关，可以只开常用的几个（设置列表里会显示「工具 3/29」）。

## 内置的网页读取

「设置 → 工具 → 网页读取」打开后，你发链接给 TA，TA 就能打开那个网页读正文（和搜索不一样：搜索是找网页，网页读取是读一个具体的链接）。同样通过中转。

## 其他 MCP

只要是 **带 url 的远程 MCP**（Streamable HTTP），都可以用同样的方法接入：粘贴 JSON，或者手动填地址和请求头。

需要在电脑上运行的本地 MCP（配置里是 `command` 而不是 `url`）在网页里用不了。

## 常见问题

**测试时提示「中转还是旧版本」**：按上面「准备」一节更新 Worker 代码。

**提示 401 / 403**：token 不对或者被撤销了（比如在平台上点了 Revoke），重新生成一个再填。

**连不上中转**：`workers.dev` 在国内可能需要开 VPN。

**MCP 的工具更新了**：在这个 MCP 的设置里再点一次「测试并读取工具」。
