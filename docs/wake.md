# 唤醒：让 TA 们自己醒来

打开唤醒以后，就算你没打开栖所，TA 们也会按时间自己醒来。醒来时 TA 自己决定做什么：给你发消息、看看邮箱、逛逛花园，或者接着睡。TA 发的消息会推送到你的手机上，打开栖所就在聊天里。

**什么时候醒**（每个角色分别设置）：

- **每隔一段时间**：比如每 2 小时，前后随机差 20 分钟。碰上免打扰时间就跳过
- **固定时间**：你自己定，比如每天 9:30、22:00。不受免打扰影响
- **TA 自己定的闹钟**：聊天时 TA 可以说「40 分钟后叫你」，到点 TA 会醒来，看到自己写的备注。同时最多 5 个，不能定在免打扰时间里
- **免打扰**：默认 3:00–10:00，可以改
- **心里攒满了**（接了心潮·念的角色）：想你想得厉害、情绪转折、做了梦醒来、有人在心潮网页上抱了 TA……心潮会通过「桥」告诉中转，TA 就醒来找你。在 TA 的唤醒设置里打开「心里攒满了就来找你」，填上服务器「栖所连接信息.txt」里的**桥口令**。免打扰时间里不会去取

时间都按北京时间算。

> 唤醒在你自己的 Cloudflare 中转上运行。需要先按 [cloudflare-relay.md](cloudflare-relay.md) 部署好中转。

---

## 第 1 步：更新中转代码

Worker 页面 → **编辑代码** → 全部换成最新的 [`relay/worker.js`](../relay/worker.js) → **部署**。

> 手机上不好全选替换？按 [worker-auto-deploy.md](worker-auto-deploy.md) 连一次 GitHub，以后就自动更新了（要先做完下面第 2 步，有了 KV 才能连）。

## 第 2 步：建一个 KV（存东西的地方）

1. Cloudflare 左边菜单 → **存储和数据库**（Storage & Databases）→ **KV** → **创建**（Create）
2. 名字随便取，比如 `qisuo`，点创建
3. 回到你的 Worker → **设置**（Settings）→ **绑定**（Bindings）→ **添加**（Add）→ 选 **KV 命名空间**（KV namespace）
   - **变量名**：`KV`（一定要是这两个大写字母）
   - **KV 命名空间**：选刚才建的 `qisuo`
4. 保存 / 部署

## 第 3 步：添加定时任务

1. Worker → **设置**（Settings）→ **触发事件**（Trigger events / Triggers）→ **添加**（Add）→ **Cron 触发器**（Cron Triggers）
2. 选「自定义」或直接填：`*/5 * * * *`（每 5 分钟检查一次）
3. 添加

## 第 4 步：在栖所里打开

1. 打开栖所「设置 → 唤醒」，上面会显示中转的情况。刚加好定时任务的话，等 5 分钟后再进来，看到「中转和定时任务都正常」就好了
2. 打开 **开启唤醒**
3. 点一个角色，打开「让 TA 自己醒来」，设好时间
4. 点 **现在叫醒 TA** 试一下

## 第 5 步：打开通知

- **iPhone**（iOS 16.4 以上）：先用 Safari 打开栖所 → 点下面的「分享」→ **添加到主屏幕**。之后**从主屏幕的图标打开栖所**，再去「设置 → 唤醒 → 打开通知」，允许通知
- **安卓 / 电脑**：直接点「打开通知」。安卓的 Chrome 通知走谷歌的服务，在国内可能收不到

点完会收到一条测试通知。通知上会显示 TA 的名字和消息开头几个字。

## 存到 Cloudflare 的东西

为了让 TA 在你没开栖所的时候也能醒来，下面这些会同步到你自己的 Cloudflare KV 里（只有你的账号能看到）：

- 打开了唤醒的角色的设定、签名、记忆、日历、对外保密
- 这个角色最近的聊天（数量按「TA 每次能看到最近多少条消息」）
- TA 用的 API 地址、Key 和模型；TA 能用的 MCP 地址和请求头（token）；搜索设置
- 手机的推送订阅

设定、记忆、聊天有变化时会自动同步（离开栖所时也会同步一次）。

**关掉**：在「设置 → 唤醒」里关掉开关，栖所会把中转上的角色清空，TA 们就不会再醒。想彻底删掉，可以在 Cloudflare 里删掉这个 KV。

## 常见问题

**显示「还没检测到定时任务」**：检查第 3 步。定时任务每 5 分钟跑一次，加好以后要等一会儿。

**收不到通知**：iPhone 一定要从主屏幕的图标打开栖所再开通知；在 Safari 网页里开不了。也检查一下系统设置里栖所的通知有没有被关掉。点「发一条测试通知」可以看到出错的原因。

**TA 醒了但聊天里没看到**：消息先放在中转上，打开栖所时取回来。`workers.dev` 在国内可能要开 VPN 才连得上中转（通知本身不需要）。

**会不会很费 API？**：每次醒来大约相当于聊一句天（用了工具会多几次）。在「最近醒来」里能看到每次用了多少 tokens，觉得多就把间隔调长。

**Cloudflare 免费额度够吗？**：免费版每天能写 1000 次 KV。每次醒来大约写 3 次，同步一次写 1 次，一般的设置完全够用。好几个角色都设成每 10 分钟醒一次的话可能会不够。

**同一时间几个角色都该醒了**：免费版每次定时任务能发的请求有限，所以一次只叫醒一个，其他的 5 分钟后再醒。
