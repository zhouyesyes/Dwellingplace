# 小世界 · 像素小屋重做（设计稿）

这里是心晴（脆脆）和 Rowan（哥哥）小屋的**新设计**：房间、人物、动作、互动的定稿和生成它们的代码。
现在 app 里用的还是旧的小屋（`src/components/room/CuiRoom.vue`、`RowanRoom.vue`），这些设计**还没实装**。
以后实装时先读这份说明，图在 `rooms/out/`、`chars/out/`。

## 怎么重新生成

需要 Node 和 Playwright（脚本里写死了 `/opt/node-tools/node_modules/playwright/index.mjs`，换机器要改成自己的路径）。

```sh
cd rooms && node render.mjs          # → rooms/out/cui-final(@3x).png、rowan-final(@3x).png
cd ../chars
node sheet.mjs                        # 先把小人导出成图（out/urls.json，中间文件）
node page.mjs                         # 人物-设定.png
node room.mjs                         # 人物-放进屋里.png
node turn.mjs                         # 人物-各个角度.png
node acts.mjs                         # 人物-后面的动作.png
node bubble.mjs                       # 气泡-心潮状态.png
node walk.mjs                         # out/frames-*/，再用 ffmpeg 合成动图：
ffmpeg -framerate 10 -i out/frames-cui/%03d.png -vf "split[a][b];[a]palettegen=max_colors=200[p];[b][p]paletteuse=dither=none" out/走路-cui.gif
```

## 画法（引擎）

- 等距像素：菱形格 32×16，地板 10×10，墙高 8 格（1 格高 = 16px），画布 352×320。
- 格子坐标：`gx` 沿后墙往右下，`gy` 沿左墙往左下，`h` 离地高度。投影 `P(gx, gy, h) = [176 + (gx-gy)*16, 150 + (gx+gy)*8 - h*16]`。
- `rooms/iso.js`：地板、两面墙、`box`（家具方块，看得见 +gx、+gy、顶三个面）、`quad`、`sprite`、点光源（五圈抖动，墙上 0.3 倍）。
- `rooms/light.js`：窗格、窗光投到地板/台面上（后墙窗、左墙窗都能用）。
- 窗外的景用 `planeView`：顺着窗框画，海面和窗台平行（不然窗一宽，海就一头深一头浅，像要涌进来）。
- 手机上：放大 2 倍，房间外面用深底（脆脆 `#4a3d35`，Rowan `#141a22`），左右拖动，默认在中间。

## 脆脆的屋 ·「海边渔村的日式慵懒」

- 后墙：右边一大片抬高一格的木地台（`cuiDeck`：x 4.2、y 0、宽 5.8、深 6.6），上面铺暖格子毯；床头贴后墙；毯子上矮桌（茶壶、半杯茶、本子）。
- 后墙大窗（推拉木格窗，左半扇推开）、宽窗台能坐：四个许愿瓶（沙、碎贝壳、干花瓣、海盐）、垂下来的绿萝。窗外傍晚的海。
- 下层：地炉贴左墙，横木从墙上伸出来吊铁壶（冒热气），梁下一串干辣椒；三个靛蓝坐垫。
- 左墙：海图、「记得喝水」便签在后墙空白处、三格贝壳标本；矮柜（收音机、陶罐、腌菜坛）、暖暖的粮袋（印谷穗，撒几粒小米）；推拉纸门（推开一扇，走廊暖光漏进来）、门边一盆植物。
- 地台旁一团渔网（带浮子）；台阶下一双木屐在地台前右边。
- 右前角：**暖暖的草窝**（铺软布），旁边一碟小米、一碟水。
- 光：晚霞从窗斜进来（台面比地上亮一档），地炉的火光。

## Rowan 的屋 ·「夜航书房」

- 左墙一大扇横的观星窗（窗外夜海、月亮、灯塔，光只扫到窗框），窗帘只挂靠墙角那一侧；深窗台上罗盘（开着盖）、杯子。
- 观星榻台塞进窗下墙角，两面贴墙：下面抽屉，窄垫、深蓝毯子，侧面两级台阶，大衣搭在床尾。
- 后墙：大星图、书桌贴墙（上面一层架子，书不满）、绿罩铜台灯、本子、羽毛笔、墨水瓶；一排夹着的手稿；告示板；另一个书架挪到门边。
- 后墙右头窄门，开一半，走廊暖光。
- 左墙前段一排吃的柜子：面包、果酱、罐头、一碗苹果；墙上搁板一排玻璃罐（米、咖啡豆、饼干、茶叶）。
- 地上：望远镜（三脚架）、地毯、摊开的海图、几张报纸、废纸篓；窗前一盆植物。
- 光：只有月光（带三格窗影，照到地上和书桌）和台灯。

## 人物（`chars/chars.js`）

两头身 Q 版，参考 Stardew 那种画风：一圈深色描边（自动加，8 邻域），大色块。每个人在 32×32 以内。

- **心晴**：橙红短发（`#E4603A`）发尾外翘；**方案 A** 靠中间偏右一缕蓝（过渡 `#8B4A5A` → `#2E4A6B`），方案 B 纯橙红。深棕眼、不戴帽。米白棉麻罩衫（袖子挽到手肘）、赭红短外褂敞开、靛蓝宽腿裤卷裤脚、木屐。腰侧棕色小挎包、胳膊下夹蓝本子。
- **Rowan**：深栗棕短发侧分（剪短、露耳朵，后脑勺保留头发），深色眼、温和。暖白衬衫、苔绿开襟外套、胸口小黄铜罗盘针、藏蓝长裤、棕短靴。
- **暖暖**：一只圆滚滚的黄色小鸡（头顶一撮毛、橙色小嘴、小翅膀），比小人矮一截，抬头看人，和心晴睡一块儿。
- 侧脸是圆的（没有凸出来的鼻尖）。

### 已经画好的帧

- 三个都有：正面、右侧、背面（左侧 = 右侧镜像）；往前走 / 往旁边走 / 往里走各两帧（暖暖是一蹦一蹦）。
- 心晴：窗台上坐着看海（背影）、地台边坐着腿垂下来抱本子、被点到站起来（眯眼笑）、坐垫上烤火、蹲下逗暖暖（正面 + 侧面）、和暖暖一起睡觉。
- Rowan：书桌前写字（正面 + 背影两帧，手会动）、待机抬手抬头、站着望灯塔（背影）、站着翻书（侧面）、躺在榻台上看星星、睡着。
- 暖暖：睡觉、啄小米两帧。

## 互动（实装时要做的）

- **走动**：每间屋设几个点（脆脆：地炉边、地台边、窗台、暖暖窝旁；Rowan：书桌、窗边、书架、吃的柜子、榻台）。按当时的心情/状态（沿用现在那套）挑一个点走过去，换成对应动作，待一会儿再换。要做能走的区域，家具挡住走到后面的人。
- **点人 → 房间下面冒气泡**：第一行他现在在干嘛；第二行**心潮的连接状态**（● 已连接 + 最近一次记下/翻了什么；● 正在同步…；● 没连上 + 上次连上的时间、点一下重连）。脆脆的气泡米白，Rowan 的深色配金边。样子见 `chars/out/气泡-心潮状态.png`。气泡里的字现在是示例，实装时读真实的心潮状态。
- **书桌上的本子 → 打开信箱**（就是现在的 `LetterSheet`，「TA 的来信 / 我写的 · 写信」）。旧小屋里「小本子跳到记忆页（/memory）」那个入口**去掉**。
- **黑匣子**：现在只冒一句话。先做一个上锁的空页面放着，之后再填。
- **会动的**：窗外灯塔的灯闪、海面反光；窗帘被风吹（3–4 帧）；地炉的火苗跳。
- **能点的**：火、台灯点一下开/关（关了屋里那圈暖光也收掉）；门点一下推开/关上（开着才有走廊的光）。
- 之后可能接更多东西，现在只接信箱。
