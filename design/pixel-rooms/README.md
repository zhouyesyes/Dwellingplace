# 小世界 · 像素小屋（设定说明）

心晴（脆脆）和 Rowan（哥哥）的像素小屋。**已经实装**，这份说明记着「长什么样、为什么这样、代码在哪」，以后改小屋先读这里。

- app 里的代码：`src/lib/pixelroom/`（引擎、两间屋、人物、走动），页面 `src/components/room/PixelRoom.vue`，接在 `src/views/RoomView.vue`（气泡、信箱、黑匣子）。
- 这个文件夹：设计稿和出图用的脚本（`rooms/`、`chars/`），图在 `rooms/out/`、`chars/out/`。
- **改屋子时两边一起改**：app 那份比设计稿多了深度、点到的东西（tag）、开关状态、会动的部分。

## 画法（引擎 `iso.js`、`light.js`）

- 等距像素：菱形格 32×16，地板 10×10，墙高 8 格（1 格高 = 16px），画布 352×320。
- 格子坐标：`gx` 沿后墙往右下，`gy` 沿左墙往左下，`h` 离地高度。投影 `P(gx, gy, h) = [176 + (gx-gy)*16, 150 + (gx+gy)*8 - h*16]`。
- `box` 家具方块（看得见 +gx、+gy、顶三个面）、`quad` 任意平面、`sprite` 字符画贴图；点光源五圈抖动（墙上 0.3 倍）。
- 窗光：`light.js` 从地板/台面往回找窗上的点，穿过窗格就亮（后墙窗、左墙窗都行）。
- 窗外的景用 `planeView`：顺着窗框画，海面和窗台平行（窗一宽，海平线水平会显得一头深一头浅，像要涌进来）。
- 每个像素还记着：**深度**（gx+gy，越大越靠前）和**是什么东西**（tag：window、door、mailbox、blackbox、fire、lamp……）。小人画的时候，前面有家具的像素不画（被挡住）；点哪里就看那个像素的 tag。

## 手机上

- 屋子放大 2 倍，左右拖着看（`.scroller` 横向滚动），一打开停在中间；上面空的 20px 裁掉。
- 屋子外面是同色调的深底：脆脆 `#4a3d35`，Rowan `#141a22`。
- 底图画一次（手机上大概零点几秒）。开关火/灯/门、有新信时重画底图；会动的东西每 0.09 秒在底图上叠一层。

## 脆脆的屋 ·「海边渔村的日式慵懒」

- 后墙右边一大片抬高一格的木地台（`cuiDeck` x 4.2、y 0、宽 5.8、深 6.6），铺暖格子毯；床头贴后墙；毯子上矮桌（大茶壶、半杯茶、本子）；床上扣着一本书、被子乱着、被角垂下来。
- 后墙大窗（推拉木格窗，左半扇推开），宽窗台能坐：四个许愿瓶（沙、碎贝壳、干花瓣、海盐）、垂下来的绿萝。窗外傍晚的海、小帆船、两只飞鸟。
- 地炉贴左墙：横木从墙上伸出来，绳子吊铁壶（冒热气），梁下一串干辣椒；三个靛蓝坐垫。
- 左墙：海图、三格贝壳标本；后墙空白处「记得喝水」便签；**门边墙上挂信箱**（浅海蓝木箱、白边、红旗）；矮柜（收音机、陶罐、腌菜坛）；暖暖的粮袋（印谷穗，撒几粒小米）；推拉纸门、半截暖帘、门边一盆植物。
- 后墙左角一大盆植物、带靠背的小凳挂草帽；地台旁一团渔网（带浮子）；木屐在地台前右边。
- 右前角**暖暖的草窝**（铺软布），旁边一碟小米、一碟水。
- **黑匣子**：床尾地台上的深木小箱子，铜包角、铜锁。
- 光：晚霞从窗斜进来（台面比地上亮一档），地炉的火光。

## 人物（`folk.js`，设计稿 `chars/chars.js`）

两头身 Q 版，像 Stardew 那种：一圈深色描边（自动加，8 邻域）、大色块；每个人在 32×32 以内。侧脸是圆的，没有凸出来的鼻尖。

- **心晴**：橙红短发 `#E4603A` 发尾外翘，靠中间偏右一缕蓝（`#8B4A5A` → `#2E4A6B`，方案 A；方案 B 纯橙红没用）。深棕眼。米白罩衫挽袖、赭红短外褂敞开、靛蓝宽腿裤卷裤脚、木屐；腰侧棕色小挎包、胳膊下夹蓝本子。
- **Rowan**：深栗棕短发侧分（露耳朵，后脑勺留着头发不秃），深色眼、温和。暖白衬衫、苔绿开襟外套、胸口小黄铜罗盘针、藏蓝长裤、棕短靴。
- **暖暖**：圆滚滚的黄色小鸡（头顶一撮毛、橙色小嘴、小翅膀），抬头看人，和心晴睡一块儿。吃小米（不吃鱼）。

## TA 在屋里干嘛（`scene.js`）

- 每间屋几个点（nodes）连成路（edges），TA 走最短的一串点过去；走路用正面/背面/左右侧各两帧。
- **待的地方（spots）**，按心潮里的心情挑（心情里有这些字就更常去），待 25–55 秒再换：
  - 脆脆：窗台上坐着看海（背影）、地台边坐着腿垂下来、坐垫上烤火（火灭了换一句）、蹲在窝边逗暖暖、在屋里转转（点她会眯眼笑）；睡着了就和暖暖一起躺在床上。
  - Rowan：侧身坐在书桌前写航海日志（手会动；台灯关了是「借着月光写字」）、站在窗边望灯塔、在书架前翻书、在柜子前找吃的、躺在榻台上看星星、在屋里走走；睡着了躺在榻台上。
  - 暖暖：平时在窝里（睡一会儿、醒一会儿），时不时蹦到碟子那儿啄小米；心晴来逗它时醒着抬头看。
- 睡没睡、心情：心潮快照里的 `runtime.consciousness`、`emotion.shown/label`。
- **躺在床上**（睡觉、Rowan 看星星）不是站着的小人图：屋子重画一遍（`state.bed`），顺着床躺好——侧着脸躺在枕头上、露出上半身（`folk.js` 的 `LYING`：侧面小人转 63° 顺着床），被子从腰盖下去、腿那里鼓起来、被角垂到床边；睡觉一定闭眼（Rowan 看星星时睁眼）；脆脆的暖暖窝在枕头边。睡着时头顶飘小小的 z。点床就是点 TA。

## 点了会怎样

- **点 TA**：房间下面冒气泡。第一行 TA 在干嘛；第二行心潮：● 已连接（最近一次心里动了一下是什么时候）/ ● 正在同步… / ● 没连上（点一下重连）/ 还没接心潮。旁边「去说话 / 轻轻叫醒」。
- **点东西**：同样的气泡，先写是什么，再一句话。脆脆的气泡米白深棕边，Rowan 的深色金边。
- **信箱**：气泡说有没有新信，按「打开信箱」才打开（就是心潮的信箱 `LetterSheet`）。有新信：小旗竖起来、投信口露出半封信。
- **黑匣子**：气泡 +「看看」→ 一个上锁的空页面（`BlackBoxSheet`），以后再往里放东西。
- **火、台灯、门**：点一下开、再点一下关。关了屋里那圈暖光也收掉；门开着才有走廊的光。（开关状态现在不记住，再进来又是开的。）
- **会动的**：窗外灯塔一亮一暗、星星眨眼、海面的光、飞鸟；Rowan 的窗帘、脆脆门口的暖帘被风吹；地炉火苗跳、壶嘴冒热气。
- 小本子不再跳记忆页（记忆在别的地方能看）。

## 还没做 / 做不了

- 信不能删：心潮信箱接口只有写信、标已读、开锁，没有删除（要心潮那边先加）。
- 开关状态不保存；人走路会穿过地上很矮的东西（路线尽量避开了）。
- 之后可能接更多东西，现在只接了信箱。

## 重新出图

需要 Node 和 Playwright（脚本里写死了 `/opt/node-tools/node_modules/playwright/index.mjs`，换机器改路径）。

```sh
cd rooms && node render.mjs        # rooms/out/*-final(@3x).png、*-final-有信
cd ../chars && node sheet.mjs && node page.mjs && node room.mjs && node turn.mjs && node acts.mjs && node bubble.mjs && node walk.mjs
ffmpeg -framerate 10 -i out/frames-cui/%03d.png -vf "split[a][b];[a]palettegen=max_colors=200[p];[b][p]paletteuse=dither=none" out/走路-cui.gif
```
